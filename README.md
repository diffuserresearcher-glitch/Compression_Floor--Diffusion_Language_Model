# Results

Every number in the paper traces to a file here. Nothing in this directory is regenerated by `scripts/make_figures.py`; the script only *reads* these.

## Compression floor (notebook 01, Harness A)

| File | Contents |
|---|---|
| `floor_grid_aggregate.csv` | One row per (block_size, tokens_per_step) cell: correct, boxed, repeat4, progress, redundancy, coverage, stop-reason fractions |
| `floor_grid_per_problem.csv` | One row per (cell, problem): 400 generations total. Source for the bimodality figure |
| `floor_grid_raw.json` | Full raw sweep output including generated text |

## SFT and the main benchmark (Harness B)

| File | Contents |
|---|---|
| `benchmark_100_all_arms.json` | **The primary result.** All 10 configurations (raw, masked/dense500/dense1500 x 3 stages) on 100 problems at t=1 and t=2, with bootstrap CIs, per-tier breakdowns, repeat-4, collapse rates, and significance tests |
| `sft_curriculum_benchmark.json` | The earlier 40-problem curriculum results, superseded by the above and kept for provenance |

## OPSD (notebooks 04, 05)

| File | Contents |
|---|---|
| `opsd_precondition_results.json` | Screening yield across sampling settings and model families; distillation loss-collapse outcome |
| `overlap_topk_results.json` | Overlap Top-K for both teacher constructions over 6,224 denoising states, the measurement explaining the loss collapse |

## Figures

Four figures, all regenerable via `python scripts/make_figures.py`:

| File | Shows |
|---|---|
| `figures/fig1_bimodality.png` | Per-problem repeat-4 pooled over both block sizes, n=400 |
| `figures/fig2_benchmark100.png` | n=100 accuracy by arm and stage with 95% CIs, both schedules |
| `figures/fig3_repeat4_100.png` | Repeat-4 degeneration signature across arms |
| `figures/fig4_overlap_topk.png` | Teacher-student Overlap Top-K, both constructions |

`figures/supp_*.png` are supplementary views (per-cell heatmaps, per-difficulty breakdown) not included in the paper.

## Before comparing anything across these files

Read `../docs/EVALUATORS.md`. Two harnesses are represented here and their numbers are not interchangeable.
